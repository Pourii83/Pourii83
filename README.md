## 📑 Summary

I build and run **real systems people use**: e-commerce on nopCommerce, insurance and finance back offices on ASP.NET Core and ASP.NET Zero, and a self-hosted messenger with end-to-end encrypted chats and video calls. I design them, write them, and deploy them myself, from the database to Nginx.

I care about **architecture, naming, clean code** and a UI that feels finished. Every project lives next to a plain-Markdown engineering vault (decisions, specs, build logs), and I use AI tooling every day to move faster without cutting corners.

- 🔭 Working on **[Flock](https://github.com/Pourii83/Flock)**, a self-hosted messenger for web, Android and Windows
- 🌱 Growing in **React / React Native** and **Python / Django**
- 🎮 Writing **Lua addons** for a vanilla WoW client in my spare time
